# Python Quiz Game

A simple quiz game built with Python. Test your knowledge by answering a series of questions and see how well you score.

## Getting Started

1. Make sure Python 3 is installed.
2. Open a terminal in this project directory.
3. Run the game with:

	```bash
	python main.py
	```

	If your system uses `python3`, run `python3 main.py` instead.

## How to Play

- Start the program from the terminal.
- Read each question and enter your answer when prompted.
- Your score is shown as you complete the quiz.

## Project

This project is written in Python and is intended as a simple, interactive command-line quiz game.
